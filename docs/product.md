# 星镜产品范围

## 已确认方向

2026-10-26用户要求在星笺之外再开发一款截图软件，参考Snipaste，必须考虑区域预判与图片边框、背景等编辑亮点；明确接受「星镜 Starshot」名称，并选择macOS与Windows同等重要。本次不开发重复的星伴，不删除星笺已有能力。

默认中文、星空主题、本地优先；动作使用「开始截图」「导入图片」「贴到桌面」「导出图片」等直观名称。无账号、云后端、遥测和启动联网。主界面五套外观继承系列偏好，图片背景独立于界面主题。

## 已有实现

| 功能 | 当前实现与入口 |
| --- | --- |
| 原生截图 | xcap冻结各显示器，隐藏主编辑器后生成独立覆盖层；`src-tauri/src/desktop.rs` |
| 区域预判 | 系统可见窗口候选与受限矩形边缘检测；`src/geometry.ts`、`CaptureOverlay.vue`。候选不保证完美识别，不是系统控件树访问 |
| 精细选择 | 点击候选、Shift临时手动选择、Tab循环候选、拖动/8向调整；方向键移动1px，Shift为10px，Alt改大小；Enter确认/Esc取消；放大镜与HEX |
| 原图编辑 | 原图保留，所有标注存原图坐标；裁剪与标注/美化共用撤销重做，最多60步；最近图片恢复各自编辑；`src/App.vue` |
| 标注 | 箭头、矩形、椭圆、画笔、荧光笔、文字、数字序号、马赛克；马赛克输出为实际替换后的扁平像素，无隐藏原图层；`src/editor.ts` |
| 美化 | 6种渐变预设和双色自定义、纯色/透明/本地图片背景；留白0–200px、圆角0–100px、边框0–24px、阴影0–80px、5种比例 |
| 导出 | PNG/JPEG、1×/2×；JPEG透明区白底；原生以所选扩展名编码并原子保存，成功返回完整路径，取消保留编辑；浏览器仅显示下载已发起 |
| 贴图 | 最多12张独立置顶窗，原生拖动、缩放、透明度、旋转翻转；空格/双击切换工具条；Esc关闭 |
| 快捷键与托盘 | 开始截图、贴最近截图原图、打开编辑器、恢复贴图鼠标操作、关闭贴图、退出；冲突报错而非启动崩溃。独立透明托盘图标：macOS单色模板，Windows紫色主体加白色外缘 |
| 更新与恢复 | 手动检查 GitHub 更新，先下载验签，再弹「安装并重启」；可稍后安装并继续编辑。确认安装时保存最新会话与旧应用，成功自动重启；`UpdateSettings.vue`、`session.ts`、Rust `updater.rs` / `recovery.rs` |
| 隐私 | 默认不截图，不读/监听剪贴板；只在显式复制时写图片。图片/最近会话/编辑平时只在内存；仅外观名写本机localStorage。手动备份及安装更新时显式保存恢复点，恢复点包含完整原图且不上传 |

同一台显示器内选区支持完整截图；多屏分别创建覆盖层，一次确认一个显示器上的选区。macOS使用系统逻辑坐标定位覆盖层，以实际PNG/逻辑尺寸转换选择像素；Windows定位使用物理像素。不同DPI、负坐标、多屏及全屏程序还需要原生矩阵验收。

## 资源限制与行为

- 前端导入不超过32MB，最长边16384、2400万像素；原生截图每屏4000万像素，最多8屏，合计8000万像素。
- 输出最长边16384、最多6400万像素；原生解码数据上限64MB。2×会将总像素变为4倍，超限明确拒绝。浏览器Canvas实际分配能力还受设备内存限制。
- 最近会话最多6张原图，原图合计4800万像素；超限按最旧顺序移除。背景图、编辑快照与渲染缓冲另占内存，此预算不是进程总内存硬上限。
- 图片不自动保存；关闭应用会失去未导出且未备份的会话。手动恢复点与更新前恢复点可重建原图、标注、裁剪、美化、背景和主题，不包含撤销历史或桌面贴图，启动不自动恢复。
- 全局贴图快捷键贴最近截图原图；美化后的图片用编辑器「贴到桌面」。第一版快捷键固定，冲突时改用按钮。
- 关闭主窗口隐藏到托盘，不等于退出；退出后所有贴图与内存会话清除，已创建的本地恢复点保留。
- 截图失败保留原有编辑，取消覆盖层回到主窗口；截图预览模式始终使用原创素材。

## 竞争参考与未实现范围

参考[Snipaste官网](https://www.snipaste.com/)明确列举的窗口/元素检测、像素控制、取色、多屏/HiDPI、贴图变换与标注能力。当前实现是独立第一版，不能据此宣称全量等价。

| 待办 | 验收重点 |
| --- | --- |
| 系统控件级识别 | Windows UI Automation / macOS Accessibility的最小权限和跨进程控件边界，不能用固定演示框充当真实识别 |
| 滚动长截图 | 滚动采集、去重拼接、固定页眉、取消和大图资源限额 |
| OCR | 本地识别、系统能力可用性、中文精度与用户可选择语言 |
| 可配置快捷键/更多采集方式 | 热键冲突反馈与旧热键解除；窗口/全屏的显式快捷动作 |
| 图片编辑增强 | 高斯模糊、对象选择/单独编辑/删除、直线/折线、图片旋转翻转、自由构图、设备边框、文字水印、批处理 |
| 贴图增强 | 分组、穿透按钮、缩略图、跨重启恢复、GIF/文本/HTML贴图；恢复鼠标操作路径先保证可靠 |
| 跨屏连续选区 | 不同DPI、负坐标、纵向显示器与多个工作区一致性 |
| 发布验收 | Windows实机测试、平台签名/公证、真实安装升级/失败恢复和正式发布；更新链路已有实现，不能将测试替代发行验收 |

平台目标同等重要不等于当前验收对等；当前机器能做的macOS构建和未来Windows原生验证必须分开记录。
