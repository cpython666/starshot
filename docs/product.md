# 星镜产品范围

## 已确认方向

2026-10-26用户要求在星笺之外再开发一款截图软件，参考Snipaste，必须考虑区域预判与图片边框、背景等编辑亮点；明确接受「星镜 Starshot」名称，并选择macOS与Windows同等重要。本次不开发重复的星伴，不删除星笺已有能力。

默认中文、星空主题、本地优先；动作使用「开始截图」「导入图片」「贴到桌面」「导出图片」等直观名称。无账号、云后端、遥测和启动联网。主界面五套外观继承系列偏好，图片背景独立于界面主题。

2026-10-26用户进一步确认产品分工：星镜专注截图及相关标注、贴图、美化，当前会话最近6张图片满足需要；长期剪贴板历史由星笺负责。持久截图历史不作为星镜的功能缺口或待办。现有手动备份、更新前会话恢复用于保护编辑进度。用户随后明确无需新增可迁移项目文件导入/导出，保留正常图片导入和PNG/JPEG导出。

同一台显示器内选区支持完整截图；多屏分别创建覆盖层，一次确认一个显示器上的选区。macOS使用系统逻辑坐标定位覆盖层，以实际PNG/逻辑尺寸转换选择像素；Windows定位使用物理像素。不同DPI、负坐标、多屏及全屏程序还需要原生矩阵验收。

## 资源限制与行为

- 前端导入不超过32MB，最长边16384、2400万像素；原生截图每屏4000万像素，最多8屏，合计8000万像素。
- 输出最长边16384、最多6400万像素；原生解码数据上限64MB。2×会将总像素变为4倍，超限明确拒绝。浏览器Canvas实际分配能力还受设备内存限制。
- 最近会话最多6张原图，原图合计4800万像素；超限按最旧顺序移除。背景图、编辑快照与渲染缓冲另占内存，此预算不是进程总内存硬上限。
- 图片不自动保存；关闭应用会失去未导出且未备份的会话。手动恢复点与更新前恢复点可重建原图、标注、裁剪、美化、背景和主题，不包含撤销历史或桌面贴图，启动不自动恢复。
- 全局贴图快捷键贴最近截图原图；美化后的图片用编辑器「贴到桌面」。快捷键可在设置修改，注册冲突会保留原来可用的绑定并报错。
- 关闭主窗口隐藏到托盘，不等于退出；无会话、无待处理操作时经前后端握手释放主WebView，呼出时重建。有图片/编辑进度时保留窗口。真正退出前未备份会话提供备份并退出、直接退出、取消；退出后所有贴图与内存会话清除，已创建的本地恢复点保留。
- 截图失败保留原有编辑，取消覆盖层回到主窗口；截图预览模式始终使用原创素材。

### 打码与资源边界

- 识别只由用户按钮触发，输入为当前裁剪范围内、已合成标注/贴纸的图片像素；不自动截图、不读取剪贴板、不上传、不保存识别文本。
- 本地OCR长边最多4096，候选返回原图坐标。过小文字/复杂背景/长图可能漏识别，可裁剪重试或手工遮盖；「未找到候选」不代表图片无敏感信息。规则按整行加边距，避免猜字符位置而遗漏部分凭据。
- 识别候选与画布选择框仅用于预览；确认后变为可撤销的实心黑色遮盖，后添加贴纸/马赛克不能盖在遮盖之上。PNG/JPEG成图为扁平像素；本机恢复点仍含完整原图，不能当作脱敏文件分享。
- 单张贴纸仅内嵌PNG、最多2MiB/200万像素，当前会话实例合计8MiB/800万像素；恢复前预解码并校验。缓存随可达编辑/撤销状态清理，撤销/背景/渲染内存仍另计。
- 普通图片及编辑仍只留在内存；主题、自定义配色、截图延时、导出偏好和不含图片的美化预设可持久保存。自启动状态读取系统实际注册项；系统登录策略仍可能阻止启动。
- 恢复点及关联旧应用可由用户选择删除，无默认自动清理。统计失败显示未知并保留恢复入口；删除遇符号链接等异常会拒绝。

### 保留分工与后续

不新增持久截图历史或可迁移项目文件导入导出；养成系统、长期剪贴板历史、链接域名分类属于星笺。用户侧CLI/MCP/Skill仍是后置候选，未开通自动读取图片、恢复点或截图的接口。Windows安装/卸载证据已有，WinGet仍需单独生成并验证清单、提交官方审核；不将Homebrew接入当作Windows已上架。系统控件识别、滚动长截图与跨屏连续选区继续保留在上表。
