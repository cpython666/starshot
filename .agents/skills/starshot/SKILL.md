# 星镜 Starshot

中文、本地优先的独立截图、标注、置顶贴图与图片美化软件，Rust / Tauri 2 / Vue 3 / TypeScript。用户于2026-10-26确认名称，以及macOS / Windows同等重要；此产品不重复开发星伴。

本 skill 是本仓库所有 AI 对话共享的知识库入口。工作前读取，完成有结论的工作后按 [AGENTS.md 的维护规则](../../../AGENTS.md#项目知识库维护) 主动更新；「更新skill」表示回顾整个对话、比对并维护现有知识。本文只保留概览、关键约定和资料索引。

当前源码状态（2026-10-29）：用户明确授权中文分批提交并推送后，标注/备份修复、平台隔离、截图/贴图功能、Windows实现与验收源码及文档已通过4个中文提交推送到公开仓库`main`，对应`a8147fb`、`a4a1a17`、`d7a3a15`、`eea18d1`。后文「未提交/未推送」为此前阶段的历史状态；「未发布」仍表示未发行新的安装版。公开稳定安装包仍为v0.3.1，日用应用未替换。

## 关键约定

- 源码实现、自动测试、浏览器演示、平台构建与原生实测分别记录；不能把窗口边界或像素边缘候选称为系统控件语义识别。
- 测试用 `public/demo-workspace.svg` 或生成的原创固定像素；不读取真实剪贴板，不将真实截图、数据、日志入Git。
- 默认不截图、不监听剪贴板、不上传图片。只有显式复制才写剪贴板；平时图片会话仅内存，主题、延时、导出选项与不含图片的美化预设可保存。手动备份、退出前选择备份及更新安装前会将完整会话保存到本机恢复点，不上传，不自动恢复。
- 用户确认不做可编辑项目文件导入导出。0.3.0新增主动本地OCR→候选勾选→实心遮盖；扫描范围为当前裁剪内的图片、标注和贴纸，不含装饰背景。macOS Vision支持中英文，Windows内置模型主要识别拉丁文字/数字；结果仍需人工检查。
- 用户已确认星镜专注截图及相关编辑，当前会话最近6张足够；长期剪贴板历史交给星笺。持久截图历史不列为缺口或待办，详见产品说明「已确认方向」。
- 2026-10-27确认交互以轻量截图为先：选区底部就地标注/复制/保存/贴图，主动「更多编辑」才进入完整页面；不做星伴。此改动已随0.3.1于2026-10-28公开为稳定latest，旧0.3.0原生设置页已能发现更新。改进、性能实测和双平台升级验证边界见验证记录。
- 界面名称和动词直接说明用途。外观五套为星夜、月白、素白、青苔、暮樱，独立于图片背景。
- 2026-10-29用户确认平台特性按目标分别编译和打包：共用编辑器保留一套；原生平台代码用Rust cfg、依赖用Cargo target表、附加资源用Tauri平台配置。源码交接包可含双平台源码，不等于安装包包含双平台实现。
- 同日用户明确要求自研Windows实现和交接验收工具保留完整源码，不能只提供编译后的DLL。UIA/helper为Rust源码，当前原生验收含Rust、Python、JavaScript及C#源码；源码齐全、已提交、已推送和已发行须分别说明，不能把本地未提交文件称为已经公开。
- 无提交、推送、发布、安装的默认授权。知识库维护本身不扩展这些权限。
- 2026-10-29本机日用入口为`/Applications/Starshot.app`；用户后续授权替换为含长截图/贴图交互/悬浮预选及macOS AX的本地0.3.1构建，不能与公开v0.3.1混为一谈。用户明确同意重新登记录屏权限并开启辅助功能后，新进程两项权限预检通过；尚未代用户实际截图。不要从target/artifacts启动日用副本；安装记录及后续待办见[本机修复版](references/releases.md#本机修复版与后续待办2026-10-29)。
