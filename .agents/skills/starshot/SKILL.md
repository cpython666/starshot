# 星镜 Starshot

中文、本地优先的独立截图、标注、置顶贴图与图片美化软件，Rust / Tauri 2 / Vue 3 / TypeScript。用户于2026-10-26确认名称，以及macOS / Windows同等重要；此产品不重复开发星伴。

按仓库 [AGENTS.md](../../../AGENTS.md) 协作。范围和限制以 [README](../../../README.md)、[产品说明](../../../docs/product.md)、[验证记录](../../../docs/verification.md) 为准。源码实现、自动测试、浏览器演示、平台构建与原生实测分别记录；不能把窗口边界或像素边缘候选称为系统控件语义识别。

- 测试用 `public/demo-workspace.svg` 或生成的原创固定像素；不读取真实剪贴板，不将真实截图、数据、日志入Git。
- 默认不截图、不监听剪贴板、不上传图片。只有显式复制才写图片剪贴板；平时图片会话仅内存，外观名可独立保存。手动备份及更新安装前会将完整编辑会话保存到本机恢复点，不上传，不自动恢复。
- 界面名称和动词直接说明用途。外观五套为星夜、月白、素白、青苔、暮樱，独立于图片背景。
- 无提交、推送、发布、安装的默认授权。知识库维护本身不扩展这些权限。

实现入口、异步状态、平台坐标、导出限制和回归检查见 [架构与验证要点](references/implementation.md)。

版本与分发见 [发布指南](../../../docs/releases.md) 与 [更新和版本要点](references/releases.md)。用户确认公开仓库 `cpython666/starshot`，手动检查更新，独立签名，发布流程只产生草稿。
