# 星镜 Starshot

中文、本地优先的独立截图、标注、置顶贴图与图片美化软件，Rust / Tauri 2 / Vue 3 / TypeScript。用户于2026-10-26确认名称，以及macOS / Windows同等重要；此产品不重复开发星伴。

本 skill 是本仓库所有 AI 对话共享的知识库入口。工作前读取，完成有结论的工作后按 [AGENTS.md 的维护规则](../../../AGENTS.md#项目知识库维护) 主动更新；「更新skill」表示回顾整个对话、比对并维护现有知识。本文只保留概览、关键约定和资料索引。

## 关键约定

- 源码实现、自动测试、浏览器演示、平台构建与原生实测分别记录；不能把窗口边界或像素边缘候选称为系统控件语义识别。
- 测试用 `public/demo-workspace.svg` 或生成的原创固定像素；不读取真实剪贴板，不将真实截图、数据、日志入Git。
- 默认不截图、不监听剪贴板、不上传图片。只有显式复制才写剪贴板；平时图片会话仅内存，主题、延时、导出选项与不含图片的美化预设可保存。手动备份、退出前选择备份及更新安装前会将完整会话保存到本机恢复点，不上传，不自动恢复。
- 用户确认不做可编辑项目文件导入导出。0.3.0新增主动本地OCR→候选勾选→实心遮盖；扫描范围为当前裁剪内的图片、标注和贴纸，不含装饰背景。macOS Vision支持中英文，Windows内置模型主要识别拉丁文字/数字；结果仍需人工检查。
- 用户已确认星镜专注截图及相关编辑，当前会话最近6张足够；长期剪贴板历史交给星笺。持久截图历史不列为缺口或待办，详见产品说明「已确认方向」。
- 界面名称和动词直接说明用途。外观五套为星夜、月白、素白、青苔、暮樱，独立于图片背景。
- 无提交、推送、发布、安装的默认授权。知识库维护本身不扩展这些权限。
